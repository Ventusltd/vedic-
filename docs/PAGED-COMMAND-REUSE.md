# VEDIC command search and reuse

The dictionary starts with a compact, alphabetical index of the full vocabulary, with 100 rows per page. Search and filters use that index, including aliases, symbols, groups and recorded Modular Star family IDs. Open a meaning or select View code to fetch its detail shard and any declared composition components. Each loaded shard is reused during that page session. Related commands are grouped for discovery by labels. Review source, units, constraints and dependencies before reuse.

The immutable command registry and previous releases are preserved. CI generates the index and detail shards for the current Pages release. The primary interface omits the continuous-prose reader. Earlier prose experiments remain in the existing archives.
