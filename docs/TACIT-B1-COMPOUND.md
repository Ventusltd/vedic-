# TACIT B1 T17 compound execution

Uses A1's `vedic.compound-plan.v1` (Neural #7200136414), original admitted ORIENT archive and T16 bound receipts. No new parser, source code generation or admission. `tools/tacit_b_compound.py`: `execute_compound(bridge,resolver,plan,context,assert_current)` and `verify_compound(bridge,resolver,plan,context,assert_current,receipt)`. resolver is trusted exact staged A1 Resolver. Host recomputes the full plan from text and named points, then checks canonical bytes, explicit keys, units and admitted operation. Context is T16 host generation/selection/challenge; assert_current() is required, must raise on stale/unknown epoch and guard final signature externally. Same callback before and after every actual operation. No callback or parser comes from user input.

Receipt `tacit-b.compound-execution.v1` contains plan, context, state (EXECUTED_INTERNAL, PARTIAL_EXECUTED, ABSTAIN), steps [{id,from_point,to_point,values,units,bound_receipt}], comparison (null or original refused comparison with input receipt IDs and value:null), independent_review, rights and receipt_sha256. No hidden nearer decision, even for equal distance. No arbitrary step operation or new dependencies. Comparison references actual intermediates, but no arithmetic comparison executed without admission. Existing nearest/electrical candidate packets unchanged. E1 owns origin signing, trusted host lifecycle and dependency observations. C1 owns independent certification.

Earth model unchanged: WGS84 named longitude/latitude degrees, spherical radius 6378.137 km, geographical great-circle distance and initial bearing, not route length. Existing undefined heading refusals retained.
